# NYAN TAKEOVER · исходные визуальные материалы

Все файлы подготовлены для Nyan Wallet. Никакие товары или награды пока не
активированы: это комплект графики, который можно проверить до внедрения.

| Файл | Назначение |
| --- | --- |
| `hero.png` | Главная иллюстрация события; заголовок и кнопки будут реальным HTML. |
| `badge-resident.png` | Постоянное достижение «Резидент флуда». |
| `badge-founding-resident.png` | Ограниченное по времени «01 / FOUNDING RESIDENT». |
| `badge-market-pioneer.png` | Достижение за первую покупку на рынке. |
| `badge-wallet-explorer.png` | Достижение за использование трёх функций кошелька. |
| `badge-auction-winner.png` | Достижение победителя аукциона. |
| `badge-takeover-limited.png` | Лимитированный значок для рынка. |
| `badge-economist.png` | Редкое достижение экономики флуда. |
| `skin-resident.png` | Светлый фон `.balance-card`, системный текст тёмный. |
| `skin-founding.png` | Тёмный фон `.balance-card`, системный текст светлый. |

Графические ограничения генерации: строгая пиксельная графика, точные
оригинальные персонажи (розовый котик и мишка с тыквой), ограниченная
розово-ягодная палитра; без 3D, текстового мусора, случайного декора,
поддельного интерфейса. У значков прозрачный фон, у фонов нет системных
текстов и номеров кошелька. Все тексты и индикаторы рисуются настоящим UI.

Количество экземпляров, цены, сроки и награды устанавливаются сервером,
а не запекаются в картинках.
