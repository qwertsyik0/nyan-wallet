# Редактор сводки NYAN WORLD

Вход: **NYAN WORLD → Управление → Редактор сводки**. На странице самой сводки ссылка также видна организатору.

Организатор создаёт новость, задаёт рубрику, заголовок и текст, сохраняет черновик, проверяет предпросмотр и отдельно подтверждает публикацию. Абзацы разделяются пустой строкой, разделители рубрик приводятся к `//`. Текст выводится безопасно через textContent.

Изменения опубликованной новости сохраняются отдельно от публичной версии. Снятая с публикации новость остаётся в редакторе и может быть опубликована снова. Жёсткого удаления нет. Перед закрытием несохранённого текста показывается подтверждение.

Публичная сводка читает `GET /api/world/news/feed` без Telegram-авторизации. Только опубликованные снимки возвращаются читателям, без черновиков и служебных полей. При недоступности API остаётся предыдущий встроенный выпуск с сообщением о невозможности обновления. Успешный пустой ответ скрывает все старые новости.

Редактор и запись требуют действующую Telegram Mini App авторизацию и проверку прав организатора на сервере. UUID операций сохраняется при повторе запроса. Изменения из устаревшей формы отклоняются по ревизии; текст остаётся в форме. Все записи аудируются в nw_audit. Бюджеты, личные балансы и права игроков не изменяются.

Существующие 18 новостей импортируются из server/world_news_seed.json один раз. Повторная установка не заменяет отредактированные тексты и не публикует снятые новости. Импорт сохраняет исходный порядок, новые записи идут первыми.

## Установка

Запустить на VPS API кошелька под root:

```bash
python3 tools/install_world_news_editor.py --ref COMMIT_SHA
```

Установщик загружает файлы указанного коммита, добавляет регистрацию к локальному server/__init__.py, сохраняет резервную копию, перезапускает nyan-wallet и проверяет health, публичный feed и маршруты редактора. При ошибке возвращает прежние файлы. Добавленные таблицы и перенесённые записи при откате сохраняются; существующие данные не удаляются.

GitHub Pages публикует интерфейс отдельно. До установки серверной части публичная страница показывает встроенную сводку, а редактор сообщает, что его серверные маршруты ещё не установлены. После установки работа редактора не требует коммитов новостей или перезапуска API.

Редактор публикует текст на странице сводки. Рассылка в Telegram и загрузка изображений в эту версию не входят.
