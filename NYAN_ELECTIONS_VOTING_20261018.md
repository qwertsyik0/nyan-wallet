# Nyan Elections · тайное голосование (18.10.2026)

## Состояние и маршруты
- Зарегистрированные пользователи Nyan Wallet могут голосовать независимо от членства в партии. Один подтверждённый Telegram ID получает один голос на сезон, выбор неизменяем.
- Вкладка «Выборы» открывает ./elections-vote.html. Показаны эмблема, председатель, точный краткий отрывок из опубликованной программы, полная программа и подтверждение.
- Фаза \`campaign\`: голосование **закрыто**; владелец видит предварительный бюллетень.
- \`POST /api/elections/owner/voting/open\`: только владелец; создаёт **снимок допущенных партий** и переводит сезон в \`voting\`. Не имеет таймера. По умолчанию никто не голосует до этого действия.
- \`POST /api/elections/voting/cast\` с \`{"party_id": ID}\`: только подписанный Telegram initData, учётная запись кошелька, отсутствие бана, партия из зафиксированного бюллетеня. При повторе идентичного запроса идемпотентный ответ, при попытке изменить выбор HTTP 409. Season row lock защищает от голосования после закрытия.
- \`GET /api/elections/voting/status\`: собственный голос, бюллетень; только владелец видит общий счётчик до закрытия. Публичные сводные результаты до закрытия отсутствуют.
- \`POST /api/elections/owner/voting/close\`: только владелец, без таймера, перевод в \`results\`. После закрытия публикуются обезличенные числа по партиям.
- Предыдущие скрытые из интерфейса партии «САП» и «Антонианство Шаматовский Дом» исключены из серверного бюллетеня. Данные партий и членство не удаляются.
- Данные хранятся в \`election_ballot_controls\`, \`election_ballot_parties\`, \`election_votes\`. Нет транзакций кошелька, Stars или наград.

## Перед открытием
1. Выполнить GitHub Actions checks и отдельный интеграционный тест \`python tools/test_elections_voting.py\`.
2. **Установить новый backend-код на FirstVDS и перезапустить сервис только после синтаксической проверки**, убедиться в \`/api/health\` и подписанном \`/api/elections/voting/status\`. Публикация только HTML/JS не включает API на текущем VPS.
3. Войти в Nyan Elections от имени владельца, открыть предварительный бюллетень и перепроверить именно **допущенные** партии.
4. Только после проверки вручную нажать «Открыть голосование». Для пользователей оно остаётся недоступным до этого действия.

Не обещать защиты от всех мультиаккаунтов: один Telegram ID = один голос. Дополнительная проверка риска может выполняться по существующим правилам антифрода отдельно.

- Владелец может после опубликования результатов нажать «Архивировать сезон»: POST /api/elections/owner/voting/archive. Голоса остаются в БД, фаза переходит в closed. После этого можно открыть новый сезон обычной формой регистрации.
