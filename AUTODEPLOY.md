# Автообновление @nyancash_bot (VPS)

## Что уже обновляется само

- **Nyan Wallet API** размещён на Render (`nyan-wallet-api`), ветка `main`, `autoDeploy: yes`. Для него ничего на VPS перезапускать не требуется.
- **Мини-приложение** находится в этом GitHub-репозитории; публикация GitHub Pages настраивается отдельно от серверного бота.
- **Telegram-бот** запускается на VPS из `/home/nyanteam/new_bot`; для него нужен этот установщик.

## Один запуск в Termius

Зайти под пользователем, который владеет ботом, и выполнить:

```bash
cd /home/nyanteam/nyan-wallet && git pull --ff-only && python3 tools/nyan_bot_autodeploy.py install
```

Скрипт попытается самостоятельно определить **уже работающий** systemd-сервис бота по процессу `bot.py`, создаст задание cron (раз в минуту), сохранит конфигурацию в домашнем каталоге и сразу синхронизирует установленные модули.

Если сервис не определён, скрипт **не устанавливает cron и не завершает работу бота**. Узнать название можно командами:

```bash
systemctl --user list-units --type=service --all
systemctl list-units --type=service --all
```

После определения службы можно указать её точно:

```bash
cd /home/nyanteam/nyan-wallet
python3 tools/nyan_bot_autodeploy.py install --service ИМЯ.service --scope user
```

Для системной службы используется `--scope system` (необходимы права на перезапуск без ввода пароля). Служба уже должна быть запущена — установщик не создаёт второй экземпляр бота.

## Поведение при обновлении

1. Раз в минуту сравнивает состояние `origin/main` и последнюю успешно применённую версию.
2. Проверяет синтаксис Python в кандидатном Git worktree **до** применения.
3. Не меняет `.env`, базу данных, `bot.py`, сохранённые состояния/покупки.
4. Копирует **только ранее установленные** модули из `bot_addons/*.py` в `new_bot`. При изменении исходного архива розыгрышей обновляет `giveaway_bot.py` с преобразованием через установщик.
5. Сохраняет исходные файлы в `~/.local/state/nyan-bot-autodeploy/backups/`.
6. Перезапускает **один существующий** systemd-сервис Telegram-бота и проверяет, что он активен через 5 секунд.
7. Если запуск неудачен, восстанавливает модули и старый Git-коммит. Проблемную версию блокирует до следующего коммита либо ручной команды `retry`.

**Ограничение:** новые модули, которых раньше не было в `new_bot`, автоматически не регистрируются в `bot.py`. Автодеплой синхронизирует существующие обработчики; их программные ошибки (например, некорректный формат кнопок Telegram) синтаксическая проверка не обнаружит.

## Проверка

```bash
cd /home/nyanteam/nyan-wallet
python3 tools/nyan_bot_autodeploy.py status
tail -n 60 ~/.local/state/nyan-bot-autodeploy/deploy.log
crontab -l | grep NYAN_BOT_AUTO_DEPLOY
```

В случае ошибки после исправления кода и нового коммита автодеплой попробует снова. Для повторной попытки того же коммита:

```bash
python3 tools/nyan_bot_autodeploy.py retry
```

Выключить автообновление (не останавливает бот):

```bash
(crontab -l | grep -v NYAN_BOT_AUTO_DEPLOY) | crontab -
```

**Примечание.** Обновление на Render и GitHub Pages происходит по их собственным настройкам. Скрипт VPS не отвечает за задержки их публикации или кеш Telegram WebView.
