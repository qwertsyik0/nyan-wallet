# NYAN AWARDS 2026 — финальное голосование

## Публикация

- Клиент: `nyan-awards-vote.html`, `nyan-awards-vote.css`, `nyan-awards-vote.js`, `assets/nyan-awards/finalists/` (девять оригиналов).
- Вход из Nyan Wallet: меню «Ещё» → NYAN AWARDS; Telegram `https://t.me/nyancash_bot?startapp=nyan_awards`.
- До `07.11.2026 15:25` (UTC+3) кнопки голосования заблокированы сервером.
- Приём голосов: `07.11.2026 15:25` — `09.11.2026 00:00` (UTC+3); церемония `09.11 19:00`.
- Только две конкурсные номинации: «Легенда Нян» (Пиксель, Фишка, Муся) и «Открытие года» (Викс, Лолиська). Семь остальных номинаций доступны для просмотра, без голосования и автоматических победителей.
- Пользователь Telegram может сохранить один голос в каждой из двух номинаций и менять его до закрытия. База содержит уникальное ограничение `(voter_id, category)`; сервер проверяет список кандидатов и Telegram `initData`. Промежуточные результаты публично не выдаются.
- 50 ⭐ разыгрываются среди уникальных проголосовавших Telegram ID (владелец исключён); финальный выбор должен выполняться владельцем после закрытия.

## Сервер FirstVDS

Обновление фронтенда через GitHub Pages **не обновляет FastAPI на FirstVDS**. Перед запуском голосования установить новый серверный модуль из опубликованного GitHub:

```bash
curl -fsSLo /tmp/deploy_nyan_awards_firstvds.py https://raw.githubusercontent.com/qwertsyik0/nyan-wallet/main/tools/deploy_nyan_awards_firstvds.py
python3 /tmp/deploy_nyan_awards_firstvds.py --check
sudo python3 /tmp/deploy_nyan_awards_firstvds.py --apply
```

Скрипт проверяет хеш модуля, делает резервную копию и откатывает изменения, если FastAPI не проходит проверку здоровья/маршрутов. Он не открывает голосование вручную, не трогает балансы и не начисляет призы.

Новые маршруты:

- `GET /api/nyan-awards/official/status` — состояние, утверждённый список и собственные голоса.
- `POST /api/nyan-awards/official/vote` — подтверждение голоса.
- `GET /api/owner/nyan-awards/official/tally` — только владельцу, промежуточные подсчёты и число уникальных голосовавших.

## Проверка

1. Открыть мини-приложение из Telegram, убедиться, что до 15:25 сохранить голос невозможно.
2. После 15:25 проверить голосование в двух конкурсных номинациях на тестовом аккаунте, замену голоса и обновление страницы.
3. Проверить, что фотографии открываются целиком, а одиночные номинации не содержат кнопок голосования.
4. Проверить `https://nyan-wallet-bridge.qwertsyik.workers.dev/api/nyan-awards/official/status` без Telegram подписи — сервер должен ответить отказом, а не раскрыть данные.
