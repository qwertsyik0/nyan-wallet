# Nyan ID — общие уровни и опыт

Nyan ID остаётся частью Nyan Wallet. Уровень и XP **не связаны с балансом лапкоинов**
и не заменяют существующий ранг кошелька, который рассчитывается по экономике.

## Подтверждённая активность

| Проект | Событие | XP | Подтверждение |
| --- | --- | ---: | --- |
| Wallet | ежедневная отметка активности | 5 | `activity_checkins`, уникальна за день |
| Wallet | полученная награда за задание | 3 | `user_task_progress.reward_claimed` |
| Wallet | разблокированное достижение | 12 | `achievement_unlocks` |
| Studio | одобренная идея | 60 | `interactive_idea_submissions.status=approved` |
| Games | завершённая партия Mafia с результатом | 30 | игровые таблицы, если они доступны в той же базе |
| Games | иное подтверждённое игровое событие | 30 | запись владельца |
| Quest | завершённое участие в квесте | 70 | запись владельца |
| Shop | подтверждённый заказ | 20 | запись владельца |

Заявки на участие, открытие приложения, переводы и простое получение лапкоинов
не дают XP. Nyan Help не отслеживается.

Прогресс вычисляется из действительных завершённых событий. Ранее накопленная
активность Wallet и Studio учитывается автоматически, без миграции начислений.

## Защищённая интеграция внешних проектов

`POST /api/owner/nyan-id/experience` требует действительную подпись Telegram Mini App
в заголовке `X-Telegram-Init-Data` **и проверку владельца кошелька**.

Пример тела запроса:

```json
{
  "telegram_id": 123456789,
  "kind": "quest_completed",
  "event_key": "reincarnation_20261115"
}
```

Допустимые `kind`: `quest_completed`, `game_completed`, `shop_purchase`.
`event_key` — постоянный ID завершённого события/заказа, 3–96 символов
латиницы, цифр, `:`, `_`, `-`.

Размер XP задан сервером, его нельзя прислать в запросе. Уникальность
`telegram_id + kind + event_key` защищает от повторных начислений.
Повторный запрос возвращает `already_recorded: true`, `awarded_xp: 0`.

**Важно:** не записывайте `game_completed` для тех партий Mafia,
которые уже подтверждены игровыми таблицами, иначе одно участие будет
посчитано дважды. Для Quest отметка о записи в группу не является
доказательством завершения сюжета. После подключения собственных ботов
Quest/Shop лучше вызывать защищённую интеграцию только после проверки
реального участия/заказа. Нельзя принимать `telegram_id` или XP
из недоверенного клиентского события без серверного подтверждения.

## Уровни

Уровень 1 начинается с 0 XP. Следующий уровень требует 100 XP,
каждый последующий на 25 XP больше предыдущего.

Например: уровень 2 при 100 XP, уровень 3 при 225 XP, уровень 4 при 375 XP.

Уровень и вклад проектов доступны в ответе `GET /api/nyan-id`,
в существующей карточке Nyan ID и в экспортируемом PNG.
Текущий ранг Wallet (Новичок/Постоянник/VIP/Легенда) сохраняется отдельно.

## Рейтинг участников

Кнопка «Рейтинг Nyan ID» в уже существующей карточке раскрывает
топ 20 участников по накопленному XP и показывает собственное место.

Маршрут `GET /api/nyan-id/leaderboard` требует подпись Telegram.
При равном XP участники делят место, порядок отображения стабильный.
Пользователи с 0 XP не входят в рейтинг, но видят своё отсутствие в нём.

Для сохранения приватности в рейтинге показан только публичный
`@username` или псевдоним «Участник XXXXXXXX»; реальные имена,
Telegram ID, балансы и история покупок не раскрываются.
Новых наград, уровня доступа или прав рейтинг не добавляет.

`tools/install_nyan_id_xp_firstvds.py` обновляет тот же серверный модуль
и проверяет защищённость нового API, сохраняя локальные доработки VPS.

## Проверка

```sh
python -m py_compile server/nyan_experience.py server/nyan_id.py server/__init__.py
python tools/test_nyan_experience.py
python tools/test_nyan_id_png.py
node --check nyan_id.js
```

Слияние ветки и развёртывание требуют обычной процедуры проверки сервера.
